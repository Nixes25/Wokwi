# Checklist Breve de Pruebas

## 1) Checklist de pruebas mínimas
- [ ] El programa corre en escenario básico.
- [ ] La salida principal coincide con lo esperado.
- [ ] Se probó al menos una entrada inválida.
- [ ] Se muestra mensaje de error entendible cuando falla.

## 2) Checklist de documentación
- [ ] `docs/propuesta.md` está completo.
- [ ] `docs/caso_de_uso.md` está completo.
- [ ] `docs/plan_de_pruebas.md` incluye tabla con casos.
- [ ] El alcance mínimo está claramente delimitado.

## 3) Checklist de ejecución
- [ ] `scripts/run.sh` funciona para el lenguaje elegido.
- [ ] Existe archivo principal en `src/`.
- [ ] No se usan dependencias complejas.
- [ ] No se requiere internet para la ejecución básica.

## 4) Checklist de entrega final
- [ ] Repositorio ordenado con estructura solicitada.
- [ ] Commits con mensajes claros.
- [ ] Proyecto pequeño y viable.
- [ ] Entrega lista para revisión en GitHub Classroom.
